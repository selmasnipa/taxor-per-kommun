# Taxor per kommun

Statisk webbplats som visar fjärrvärme, elnät och VA per kommun (källa: Nils Holgersson-rapporten).

Allt ligger i `index.html` (data inbäddad). Ingen byggprocess behövs.

## Uppdatera
Ersätt `index.html` i GitHub-repot med en ny version. Render publicerar automatiskt inom någon minut.
